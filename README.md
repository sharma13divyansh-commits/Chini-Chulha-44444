## 🚀 How to Run Locally

You can run this project using any local web server:

### Option 1: Python
```bash
python server.py
# Opens at http://localhost:8085
```

### Option 2: Node.js (npx)
```bash
npx serve .
```

### Option 3: VS Code Live Server
Right click `index.html` and select **"Open with Live Server"**.
